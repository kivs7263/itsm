# Failure Log — itsm

업무 종료 시 이번 세션에서 실패·재작업이 있었으면 아래에 1줄 추가.

형식: `| 날짜 | 도메인 | 실패/재작업 내용 | 원인 | 해결 | 방지 패턴 |`

`방지 패턴` 컬럼 작성 기준:
- `없음` — 예측 불가 외부 요인
- `신규: [패턴명]` — 이 실패로 새 패턴 등록 필요
- `[agents/xxx.md#패턴명]` — 기존 패턴 미적용이 원인 → session_close 시 해당 패턴 검증# +1
